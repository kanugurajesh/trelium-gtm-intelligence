# Deeper-page collection: pass 2 versus the homepage-only baseline

`docs/FINDINGS.md` (finding B) predicted that the rubric's four operational components (c2 operational complexity, c3 named systems, c4 scale, c5 growth triggers) could not fire from homepage-level evidence, and proposed extending collection to careers, technology/integrations and press pages as the first experiment. This document is that experiment. Pass 1 (archived in `output/briefs_pass1_homepage/`) collected the homepage plus at most one about page and one careers page. Pass 2 (`output/briefs/`) adds one technology/integrations page, one press/news page and one services/capabilities page, discovered from the homepage's own navigation, at most six requests per account. Same extraction prompts, same scorer, same taxonomy; the only change is what was read.

Generated by `scripts/compare_passes.py` from committed briefs; no fetches, no model calls.
